# Python Programs Collection

A curated collection of essential Python programs demonstrating core algorithmic thinking, data structures, and problem-solving techniques.

## Programs Included
1. **Factorial Calculation (`factorial.py`)**: Demonstrates both iterative and recursive implementations with input validation.
2. **Fibonacci Sequence (`fibonacci.py`)**: Generates Fibonacci numbers using iteration and recursive memoization.
3. **Structure to Dictionary (`structure_to_dict.py`)**: Converts nested tuples, custom objects, and lists into structured Python dictionaries.
4. **Palindrome Checker (`palindrome.py`)**: Checks for string and numerical palindromes ignoring spaces and punctuation.

## How to Run
```bash
python factorial.py
python fibonacci.py
python structure_to_dict.py
python palindrome.py
```
